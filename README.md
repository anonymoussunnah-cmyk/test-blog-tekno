# Saintek News

Blog pribadi modern bergaya magazine tentang sains, teknologi, industri, dan gaya hidup di Indonesia.

## Fitur

- 🎨 Desain modern bergaya magazine
- 📱 Responsif dan mobile-friendly
- ⚡ Performa tinggi dengan Next.js 14
- 📝 5 artikel sampel dengan 3 kategori
- 🔍 Filter artikel berdasarkan kategori
- 📬 Newsletter subscription
- 📱 Social sharing
- 🌐 Bahasa Indonesia

## Teknologi

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Lucide React Icons
- date-fns untuk manipulasi tanggal
